<a id="project-context"></a>
## 📘 Project Context

This project was developed for a graded practical assignment in the **BUT Informatique** program at IUT.

The goal is to design a clean, structured, and responsive web page that visually represents an online store section dedicated to network products.


<a id="objectives"></a>
## 🎯 Objectives

- Create a realistic product listing web page
- Apply proper HTML5 structure
- Use CSS for layout, styling, and responsiveness
- Ensure the website adapts correctly to different screen sizes (desktop, tablet, mobile)
- Respect web design and accessibility basics


<a id="features"></a>
## 🧱 Features

- Static product listing layout
- Visual filters (price, length, category)
- Pagination layout
- Header, navigation menu, and footer
- Fully responsive design
- No JavaScript (visual only)


<a id="technologies-used"></a>
## 🛠️ Technologies Used

- HTML5
- CSS3

No external frameworks or libraries were used.


<a id="getting-started"></a>
## 🚀 Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/mreynaud42/tp_iut_page_web_reseau.git
   ```

2. Navigate to the project directory.

3. Open the main HTML file (tp1.html) in a web browser.

No additional setup is required.
